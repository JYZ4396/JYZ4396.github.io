# Jiayi Zhu research portfolio

The public website consists of the HTML pages and assets in this folder. It uses relative links and works without a build step.

Open `index.html` to preview it locally. To serve it at the root of a GitHub Pages site, place those files in the publishing branch and set the Pages publishing source to that branch and its root folder.

Edit the top-level pages for the introduction, list of projects, outputs, and biography. Project narratives live in `research/`; shared typography, colors, and layout live in `assets/site.css`. The CV and the 2024 and 2026 conference posters are available as PDFs in `assets/`. The North Florida map uses public-domain Natural Earth cartography, and the coverage chart uses Table 4 of the author's preprint.
